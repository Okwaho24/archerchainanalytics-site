Archer Chain Analytics — Product

FabriCatHD™

Schema-Driven Document Generation Desktop App

Overview

Executive overview

FabriCatHD™ is a production-ready, schema-driven document generation desktop application built on Tauri 2.0, React 18 and Rust. It supports drag-and-drop creation, management and publishing of templated documents, with JSON schema validation, version control and bulk generation. Native macOS, Windows and Linux builds are supported.

Capabilities

Core capabilities

Schema designer

Visual schema builder for document fields and data types, with JSON export for integration.

Template engine

Handlebars-based templating with conditional sections and loops.

Bulk generation

Hundreds of documents generated from CSV, JSON or database sources.

Export formats

PDF, DOCX, HTML, Markdown and plain-text output.

Version control

Schema and template versions tracked, with a full audit trail.

Desktop-native

Native performance with no server required; operates offline.

Applications

Target applications

Legal and compliance

Contracts, NDAs and regulatory documents generated from standardized schemas.

Business operations

Invoices, quotes, proposals and contracts with dynamic data binding.

Enterprise reporting

Annual reports, compliance filings and audit documentation.

Template commerce

Document templates sold through FormDepot™ or RaPaX™.

Commercial

Commercial terms & deployment

Perpetual license or SaaS subscription. Custom schema design, template migration and enterprise training are included.
